# Анализ рынка недвижимости Санкт-Петербурга

## О проекте
Аналитический проект по исследованию рынка недвижимости Санкт-Петербурга и Ленинградской области.

Цель исследования:
- изучить сезонность публикации объявлений
- проанализировать время продажи квартир
- исследовать динамику цен
- выявить факторы, влияющие на скорость продажи

## Данные
В работе использован датасет с информацией о недвижимости:
- дата публикации
- цена квартиры
- площадь
- количество комнат
- этаж
- тип населённого пункта

## Методы анализа
- очистка данных
- обработка выбросов (percentiles)
- агрегированный анализ
- временные ряды
- SQL (CTE, JOIN, группировки)
